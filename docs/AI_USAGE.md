# AI利用の記録

- 使用ツール：OpenAI ChatGPT / Codex。個々の利用モデル名・版は利用記録を参照。
- 使用目的：文献・原単位・埋蔵量の調査支援、AIM出力抽出、需要計算・単位確認・集計・作図コードの作成と修正、説明文の整理。
- 採用した処理：更新版AIM出力への対応、HEV/FCVとバス・貨物車の部品集計、残余の再校正、参照量の整理、代替技術と制約の条件付き計算。
- 確認状況：公開用整理では基本テストと一部の非公開入力による再計算照合を行った。AIによる数値検証と、研究者本人による原典・仮定の確認を区別する。本人の原典照合は進行中で、全項目を確認済みとはしない。
- 記録：公開コードのCommit SHA、analysis/latest/SNAPSHOT.json、docs/LATEST_VALIDATION.md。非公開の入力・出力・実行記録は別途保存。
- 会話全文・プロンプト履歴はこのリポジトリには収録していない。
