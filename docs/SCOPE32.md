# 現在の報告対象：共通32鉱物

PénélopeのScope of the study.xlsxの実際の32鉱物と一致することを検証してから集計する。
保留：C、La、Ce、Mg、Ti、Sc、Pt、Ir。保留元素の質量を他の元素へ再配分しない。

現在の本表は更新版AIM出力2611091342、世界、Baseline/300C、2020–2100年の非最適化需要。
技術・原単位ケースは既存のF_E_plus_steel_Fe_proxyを継承し、A–Fの感度表を併記する。
Fには鋼材Fe97.86%換算、FCVの補完、代表車種の転用などの仮定がある。唯一の確定値ではない。
送配電網は既存のSPSケース、エネルギー原単位はaverageを継承。Na等への最適化結果を基準需要へ混在させない。

```bash
python scripts/run_latest.py --stage results32 --check
python scripts/run_latest.py --stage results32
```

入力はconfig/latest_stages.jsonに列挙。集計結果Excel/CSVは非公開。
年次はt/year、累積は2020–2050の31年と2020–2100の81年の年次合計。
車両の内訳を車両合計へ二重加算しない。6部門合計と総量、車両内訳と車両合計を検証する。

32鉱物へ絞ることと、32元素の全材料原単位を確定することは別。
- 車両：FCVバス駆動系、合金成分、未収録元素、代表クラスとAIM区分、電池単独交換が未確定。
- 蓄電：12hはモデル設定。VRFBシェアとV原単位をAIM量へ対応させる作業が残る。
- 発電：PVのDC/AC基準、原単位の設備境界、CCS増分の扱いが残る。
- 送配電：Cu/Al以外を32鉱物の完全需要として統合できていない。
- 会計：Li等の元素/LCE境界、一次/二次供給・在庫・歩留まり・回収を統一していない。
- その他部門：基準年残余とGDPによる将来延長。2050以降の変化率固定は仮定。
- 埋蔵量：Pénélope同梱では27/32に埋蔵量、23/32に資源量。独自参照でもGe/Hf/Si/Taの4種類は条件付き。

2026–2050のPV方式転換・IEA蓄電置換は別の感度ケース。本表の2100年値には混在させない。
本集計は既知部品小計と基準年残余の条件付き需要であり、一次採掘必要量・確定不足判定ではない。
