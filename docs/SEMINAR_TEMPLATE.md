# ゼミ資料への記載テンプレート

## 分析コード・再現情報

- Repository：`https://github.com/TomokiMatsui0207/aim-mineral-demand`
- 使用した分析版：`COMMIT_SHA`（コミット固定リンクも記載）
- AIM本体／core／データ版：`AIM_SHA / CORE_SHA / DATA_SHA`
- AIM出力ID：`OUTPUT_ID`
- 図の条件：`原単位ケース / 系統ケース / HEVケース / 容量基準等`
- 図の作成コマンド：`python scripts/plot_results.py ...`
- 数値結果の状態：`暫定・条件付き／検証済みの範囲を記載`

公開範囲：分析・作図コードと手順。AIM本体、モデル出力、入力データは含めない。

新しいAIM計算が終わる前に作った図は「更新前AIM出力による暫定結果」と明記し、新版の図と混同しない。
